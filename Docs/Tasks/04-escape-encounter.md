# 04 추격대와 탈출 한 판

## 할 일

- 왕국 병사가 마차를 따라오는 첫 추격 상황을 만든다. 대포 발사 방향의 직선상에 있는 추격대를 찾아 피격과 밀려나는 반응을 연결한다.
- 테스트에 사용할 목표 거리와 내구도 피해 규칙을 정하고, 추격대가 마차에 닿았을 때의 피해와 판 종료를 연결한다.
- 첫 프로토타입은 목표 거리 도달을 성공으로, 내구도 소진을 실패로 사용하는 안으로 검증한다. 양쪽 결과에서 다시 시작할 수 있게 한다.

## 완료 조건

- [ ] 추격대가 마차를 압박하고, 조준선상에서 명중한 적은 밀려나며 빗나간 적은 계속 추격한다.
- [ ] 팀이 목표 거리 도달과 내구도 소진을 각각 재현하고, 두 경우 모두 다시 시작할 수 있다.
- [ ] 재시작하면 거리, 내구도, 추격대, 바퀴, 포탄과 대포 상태가 초기값으로 돌아간다.
