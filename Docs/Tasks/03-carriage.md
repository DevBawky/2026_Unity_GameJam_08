# 03 마차 주행과 바퀴 수리

## 할 일

- 마부석에서 채찍질하면 말과 마차의 속도를 유지하도록 하고, 현재 속도로 이동 거리를 누적한다. 주행 속도, 거리, 내구도를 HUD에서 읽을 수 있게 한다.
- 바퀴 이탈 상태를 만들고, 해당 바퀴에 접근해 수리하면 주행 상태가 회복되도록 연결한다. 첫 검증은 원하는 시점에 이탈을 발생시켜 반복한다.
- 정면 주행만으로 수리와 작업 분담을 먼저 검증한다. 좌우 조향을 포함하는 범위는 HTML5 포팅 기준을 정할 때 함께 확인한다.

## 완료 조건

- [ ] 채찍질에 따라 속도와 거리 누적이 달라지고 바퀴 이탈과 수리가 속도에 반영된다.
- [ ] 마부가 속도를 유지하는 동안 다른 플레이어가 이탈한 바퀴를 수리할 수 있다.
- [ ] 수리 중 이동하거나 입력을 반복해도 수리가 중복 완료되지 않는다.
