# 06 HUD와 개인별 작업 시야

회의록에서 프로젝트 담당(화자 2)이 UI 레이아웃을 맡았다.

## 할 일

- 탈출 거리, 마차 내구도, 이동 속도, 적재 포탄 수를 보여 주는 간결한 HUD를 구성한다. 레이아웃은 임시값으로 먼저 만들고 시스템 상태가 생기는 순서대로 연결한다.
- 전체 갑판 시야와 작업 시 확대 시야 사이의 전환을 구현한다. 확대 시에도 작업 단계와 긴급 상황이 읽히도록 안내 위치를 정한다.
- 편집기와 작은 가로형 모바일 화면에서 겹침, 잘림, 조작 요소의 가독성을 확인한다.

## 완료 조건

- [ ] 거리·내구도·속도·적재 포탄 수가 실제 상태와 일치한다.
- [ ] 각 플레이어의 카메라가 해당 플레이어의 작업 시작과 종료에 맞춰 독립적으로 전환된다.
- [ ] 가로형 모바일 화면에서도 필수 HUD와 현재 작업 안내가 겹치거나 잘리지 않는다.

## 선행 작업

레이아웃은 병행 가능하다. 작업 시야는 [01 갑판 이동과 작업 상호작용](01-deck-controls.md), HUD 연동은 [02 대포](02-cannon.md)와 [03 주행](03-carriage.md)에서 제공하는 상태를 사용한다.
