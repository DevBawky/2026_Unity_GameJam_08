# 마차 탈출 협동 게임 태스크

[킥오프 회의록](../KickoffMeetingNotes.md)에서 나온 일을 하나씩 맡을 수 있도록 태스크별 파일로 나눴다. 아래 작업 순서는 첫 리뷰에서 협동 플레이를 확인하기 위한 제안이다.

협동 플레이의 기획 의도는 [초기 게임잼 기획](../Design/아그건님이_게임잼_기획.md)에서, 기존 웹판의 동작은 [웹 프로토타입 상세 명세](<../Design/그건 님이!!! — 플레이 가능한 프로토타입 상세 명세.docx>)에서 확인할 수 있다.

현재 저장소에는 탑뷰 씬 배치와 입력 설정이 있다. 기존 HTML5 배포판의 세부 규칙은 [Unity 재제작 준비 문서](../AI/UnityProjectContext.md)에 정리돼 있다. 예를 들어 킥오프의 무한 보급 포탄 더미와 HTML5 배포판의 유한 재고는 서로 다른 규칙이므로, 첫 실험에 사용할 기준과 포팅 시 확인할 차이는 [대포 태스크](02-cannon.md)에 기록했다.
