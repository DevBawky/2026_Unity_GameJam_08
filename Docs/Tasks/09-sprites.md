# 09 기본 스프라이트와 애니메이션

회의록에서 아트 담당(화자 1)이 에셋 제작과 공유를 맡았다.

## 할 일

- 현재 Unity 화면을 기준으로 탑뷰 픽셀 아트 스프라이트를 제작한다. 각 동작은 한 방향으로 그린다.
- 말 달리기, 플레이어 대기·걷기, 아기의 요람·이동·행동 상태를 제작한다.

## 완료 조건

- [ ] 현재 화면에서 말, 플레이어, 아기의 기본 상태를 구분할 수 있다.
- [ ] 담당자 폴더에서 각 애니메이션의 프레임별 PNG와 동작 확인용 GIF를 파일명으로 구분할 수 있으며, 팀원이 Git으로 받을 수 있다.

## 선행 작업

현재 프로젝트 화면에서 바로 시작할 수 있다. 시스템 구현과 병행한다.
