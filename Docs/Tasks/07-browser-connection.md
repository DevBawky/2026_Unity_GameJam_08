# 07 Unity 브라우저 연결 검증

## 할 일

- 기존 HTML5 프로토타입과 현재 Unity 씬을 비교해 첫 리뷰에 가져갈 협동 동작과 적용할 규칙을 기록한다.
- 브라우저 실행이 가능한 최소 Unity 빌드에서 서로 다른 브라우저 세션 두 개를 같은 방에 연결하고 플레이어 이동과 간단한 공유 작업 하나를 동기화한다.
- 연결·재접속을 재현하고, 사용한 전송 방식과 실행 절차를 기록한다.

## 완료 조건

- [ ] 두 브라우저가 같은 세션에서 서로 다른 플레이어로 움직인다. 한 브라우저에서 수행한 공유 작업의 결과가 두 화면에 동일하게 표시된다.
- [ ] 한 브라우저를 닫은 뒤 다시 접속해 방과 최신 공유 상태를 확인할 수 있다.
- [ ] 팀원이 다시 사용할 접속 절차, 검증 결과, 남은 제약을 작업 문서에 기록한다.

## 선행 작업

HTML5와 Unity의 비교는 바로 시작할 수 있다. 접속 실험에는 [01 갑판 이동과 작업 상호작용](01-deck-controls.md)의 간단한 플레이어 이동과 공유할 작업 하나가 필요하다.
