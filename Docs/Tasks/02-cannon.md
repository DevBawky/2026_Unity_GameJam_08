# 02 포탄 운반과 대포 조작

## 할 일

- 포탄 더미에서 한 발을 꺼내 운반하고 적재칸에 내린 뒤, 다른 플레이어가 적재탄을 꺼내 장전할 수 있게 한다.
- 장전 → 점화 → 조준 → 발사 → 청소 순서를 연결한다. 발사 후 청소를 마치면 재장전할 수 있다.
- 첫 실험은 회의록의 무한 보급 더미를 기준으로 한다. 적재칸과 대포에 든 수량은 실제 이동에 따라 바뀐다. HTML5 배포판의 유한 재고는 포팅 기준을 확인할 때 비교한다.
- 발사 방향과 발사 시점을 추격대 피격과 연출에서 사용할 수 있게 전달한다.

## 완료 조건

- [ ] 한 플레이어가 옮긴 포탄을 다른 플레이어가 장전하고, 점화부터 청소까지 진행해 두 번째 발을 쏠 수 있다.
- [ ] 적재탄이 없거나 발사 후 청소가 끝나기 전에는 장전할 수 없다. 같은 포탄이 중복 적재되거나 소모되지 않는다.
- [ ] 적재 수가 운반·적재·장전 결과에 맞게 바뀐다.
