# 05 아기 돌보기와 방해 실험

## 할 일

- 요람에서 아기를 돌보는 행동과 돌봄이 필요한 상태의 표시를 만든다.
- 테스트용 선택지와 자원을 마련한다. 아기가 선택을 대신해 자원을 쓰는 안과 선택지 하나를 없애는 안 중 하나만 임시 적용한다. 발생 조건과 빈도는 실험용 값으로 둔다.
- 같은 상황을 방해 적용 전후로 플레이해, 역할 분담이나 대화가 늘었는지와 플레이어가 결과의 원인을 이해했는지 확인한다.

## 완료 조건

- [ ] 돌보기 행동과 방해 후보를 각각 재현하고, 무슨 일이 발생했는지 플레이 중 알아볼 수 있다.
- [ ] 적용 전후 비교에서 방해를 알아챈 시점, 팀 대응, 불편했던 지점을 기록한다.
- [ ] 실험 결과와 함께 유지·수정·제외 중 하나를 제안하고, 돌봄과 방해를 연동할지는 검증 결과를 바탕으로 논의한다.
