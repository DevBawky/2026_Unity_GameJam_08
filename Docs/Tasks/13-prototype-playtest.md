# 13 협동 프로토타입 리뷰

## 할 일

- 첫 리뷰에서는 현재 씬 배치와 임시 표시를 사용한다. 에디터에서 사람 한 명이 테스트용 동료 캐릭터와 포탄을 주고받으며 장전·발사·청소를 거쳐 재발사한다.
- 두 사람이 같은 판을 조작할 수 있게 되면 포탄을 인계할 때 서로 알아서 역할을 나누고, 작업 안내만 보고 다음 할 일을 찾는지 관찰한다.
- 주행·수리가 연결되면 포격 중 바퀴가 빠지는 상황을 추가해, 기존 작업을 멈추고 역할을 나누는지 한 번 더 확인한다.

## 완료 조건

- [ ] 이동, 작업 시작, 포탄 인계와 재발사를 이어서 실행한다.
- [ ] 첫 리뷰에서 진행이 멈춘 지점과 원인, 가장 먼저 고칠 것을 기록한다. 두 사람의 리뷰에서는 실제로 맡은 역할과 인계 시점도 기록한다.
- [ ] 수리가 포함된 리뷰에서는 이탈을 알아챈 사람과 수리를 맡은 사람을 기록한다.

## 선행 작업

첫 리뷰는 [01 갑판 이동](01-deck-controls.md), [02 대포](02-cannon.md), [06 HUD](06-hud-camera.md)의 기본 작업 안내가 필요하다. 두 사람의 온라인 리뷰는 [08 온라인 동기화](08-online-session.md)에서 공통 대포 작업이 동작한 뒤 진행한다. 바퀴 이탈 시나리오는 [03 마차 주행과 바퀴 수리](03-carriage.md) 이후 진행한다.
