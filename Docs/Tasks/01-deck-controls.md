# 01 갑판 이동과 작업 상호작용

## 할 일

- [기존 탑뷰 씬](../../Assets/Scenes/Scene.unity)의 갑판과 작업물 배치를 기준으로 플레이어 이동, 갑판 범위, 작업 가능 구역을 연결한다.
- 포탄 더미, 적재칸, 대포, 마부석, 바퀴, 요람에 접근하면 현재 가능한 행동을 안내한다. 각 작업은 이동과 행동 입력을 공통으로 사용한다.
- 먼저 에디터에서 이동과 작업 입력을 확인한다. 실제 HUD 연결에는 작업 가능 여부와 진행 상태를 전달한다.

## 완료 조건

- [ ] 플레이어가 갑판을 이동하면서 작업 지점을 오갈 수 있다.
- [ ] 사용할 수 있는 작업은 안내와 실제 입력 결과가 일치한다. 구역에서 벗어나면 해당 작업 입력이 종료된다.
- [ ] 두 작업 구역이 인접해도 한 입력으로 작업이 중복 실행되지 않는다.

## 선행 작업

현재 씬 배치와 Input System 설정으로 시작할 수 있다.
