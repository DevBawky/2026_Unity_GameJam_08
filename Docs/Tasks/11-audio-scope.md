# 11 사운드 범위와 적용 방식

## 할 일

- 프로토타입에서 소리로 전달할 동작이나 상태를 검토한다. 대포 발사나 바퀴 이탈처럼 팀원이 알아차려야 할 이벤트부터 살핀다.
- 필요한 사운드를 어떻게 마련할지와 Unity에서 어떤 이벤트에 연결할지 정한다.

## 완료 조건

- [ ] 프로토타입에 적용할 사운드와 보류할 후보가 기록돼 있다.
- [ ] 선택한 사운드마다 생성 또는 확보 방식과 Unity 적용 지점이 기록돼 있다.

## 선행 작업

범위 논의는 바로 시작할 수 있다. 재생 시점을 정할 때는 [대포](02-cannon.md)와 [마차 주행](03-carriage.md)의 상태 변경을 확인한다.
