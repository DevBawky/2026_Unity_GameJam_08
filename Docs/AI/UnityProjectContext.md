## Unity 첫 구현 순서

1. `Assets/Scenes/Scene.unity`를 Unity 에디터에서 복제해 `Assets/Prototypes/GoblinGetaway/GoblinGetawayPrototype.unity`로 시작한다. 가로 16:9 기준으로 왼쪽에는 두 마부석, 가운데에는 왕실 좌석과 포탄 더미, 오른쪽에는 포수·적재·장전 위치를 잡는다. 말은 화면 왼쪽, 기병은 오른쪽이다. 첫 검증에는 현재 배치와 도형으로 충분하다.
2. 갑판 전체를 보며 이동하고 작업 원에 들어가면 현재 작업과 행동 한 가지를 보여준다. 시작 입력은 키보드·마우스와 게임패드로 잡고, 역할 변경과 타이밍 판정부터 확인한다. 브라우저 가로 터치에서는 왼쪽 스틱 이동, 오른쪽 스틱 방향, 작업 행동 입력을 검증한다. 키보드 첫 바인딩은 WASD·마우스·Space, 게임패드는 양쪽 스틱·A 또는 R2를 기준으로 한다.
3. **장전된 대포 점화 → 조준 → 자동 발사 → 반동 → 운반 중 붙잡기 → 적재 → 장전 → 재발사**를 한 씬에서 재현한다. 첫 버전에서 사람 조작 한 명과 정해진 동작을 하는 동료를 써서 성공과 실패를 반복 검증한다. 게임 규칙은 입력·카메라·UI와 별도로 관리하고, 포탄은 더미·소지·적재·장전·사용·손실 상태를 명확히 기록한다. 봇도 같은 작업 상태와 판정을 사용한다.
4. 포탄 순환이 확인되면 웹 빌드 두 개를 같은 세션에 연결하는 기술 검증을 진행한다. 설치된 네트워크 패키지는 후보이며, 브라우저에서 실제로 연결·재연결되는 전송 방식과 배포 위치를 이때 확정한다. 점화 시점·재고·충격·작업 완료는 세션의 권한 있는 시뮬레이션에서 판정하도록 잡는다. 작업 카메라와 내 캐릭터 표시는 기기별로 처리한다.
5. 조향, 돌과 기병, 바퀴 수리, 두 왕족의 불안, 목표 거리와 재시작을 연결해 가시숲 한 판을 만든다. 사람의 이동과 작업 선택을 존중하도록 봇 세 명을 붙이고, 봇이 우선 대응할 상황을 왕족 탈출·바퀴 이탈·빈 대포에서 검증한다.
6. 3자리 방번호로 합류하는 최대 4인 플레이, 봇 교대, 방장 이관과 전원 재시작을 검증한다. 한 기기 2인 분할 시야, 다음 스테이지와 특성, 발표용 BGM은 첫 가시숲과 온라인 동작이 검증된 뒤 작업한다.

## 재현할 규칙과 통과 조건

| 항목 | 배포판 기준과 검증 |
| --- | --- |
| 역할과 시야 | 전체 1배, 포수 2배 후방 시야, 운반·붙잡기 3배, 마부·장전·왕실·수리 4배. 작업 원을 벗어나면 전체 또는 현재 운반 시야로 돌아온다. 개인 화면에서 본인만 흰 외곽선으로 표시한다. 일반 작업은 원형 게이지 바늘이 색 구간을 지날 때 행동한다. 충격이 커도 작업 종류와 성공 구간 또는 남은 심지 시간을 읽을 수 있어야 한다. |
| 조향 | 마차의 진행 방향을 기준으로 위쪽이 오른말이다. 오른말만 재촉하면 마차가 화면 아래, 왼말만 재촉하면 화면 위로 간다. 두 말의 속도가 비슷하면 직진하며 가속할 수 있어야 한다. |
| 포격 | 장전 후 점화할 수 있다. 점화 후 2.5초간 흔들리는 조준점을 옮기고, 심지가 끝나면 자동으로 한 발만 나간다. 반동은 마차와 이미 운반 중인 포탄에 전달된다. |
| 운반과 장전 | 운반 속도는 평소의 30%, 적재칸에서 자동 내려놓기. 큰 충격 때 멈추고 1.6초 안에 붙잡으면 같은 탄을 계속 운반한다. 실패나 시간 초과 시 소지 탄 한 발을 잃는다. 대포가 비었고 적재탄이 있을 때만 장전할 수 있다. 장전 성공은 적재탄을 한 발 옮기고, 실패는 한 발을 잃는다. 시작 재고는 더미 17·적재 1·장전 1이므로 첫 두 발을 쏘는 것만으로 운반이 검증되지는 않는다. 붙잡기 성공·실패의 재고 차이까지 확인한다. |
| 바퀴와 불안 | 110m 이후 충격으로 바퀴가 빠질 수 있고 첫 이탈이 없으면 155m 이후 수리 상황이 발생한다. 이탈 중 목표 속도는 정상의 57%. 장착 후 핀 고정까지 성공해야 속도가 회복된다. 왕자·공주 불안은 각각 28%·42%에서 시작해 75%에 탈출 시도, 100%에 실패한다. 더 불안한 승객을 달래면 평소 42%p, 탈출 시도 중 63%p 내린다. |
| 한 판과 성장 | 초기 내구도 100, 기본 속도 13m/s. 돌·통나무·기병 공격 피해는 각각 6·9·14. 내구도 0 또는 왕족 이탈로 실패한다. 가시숲 목표 1,000m 도달 시 클리어와 재시작을 먼저 검증한다. 이후 단계에서 목표 거리는 150m씩 늘고 공용 특성 하나를 고른다. |
| 온라인 교대 | 방장 포함 네 슬롯 중 빈자리는 봇이 맡는다. 운반 중 합류와 이탈에도 슬롯·좌표·소지 탄을 그대로 이어받아야 한다. 네 자리가 찼으면 다음 참가를 거절하고, 방장이 나가도 남은 사람의 역할·거리·진행 상태가 유지돼야 한다. |

첫 사람 간 테스트에서는 포수가 점화하면서 동료에게 알려 주는지, 운반자가 반동 때 붙잡기로 전환하는지, 장전수가 성공 여부와 다음 할 일을 구분하는지 본다. 역할 안내를 읽느라 위험을 놓친다면 확대 배율과 긴급 알림을 함께 조정한다.
