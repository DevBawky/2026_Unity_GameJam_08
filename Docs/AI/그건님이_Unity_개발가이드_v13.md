# 《그건 님이!!!》 Unity 개발 가이드 · v13

2026-11-19 · Unity `6000.3.28f1` · 웹판 `cannon-rope114`

`그건님이_전체편집프로젝트_v13.zip`에는 현재 Unity 편집 프로젝트와 v13 웹 소스·에셋을 함께 담았다. 이 문서의 수치와 동작은 웹판을 기준으로 한다. Unity 쪽은 동봉한 씬과 프리팹을 기준으로 최신 웹 동작의 이식과 호스트·클라이언트 검증을 진행한다. [웹 운영 버전](https://goblin-getaway-crew.vercel.app)

## 프로젝트 열기

1. ZIP을 풀고 `Assets`, `Packages`, `ProjectSettings`가 있는 폴더를 Unity Hub에 추가한다. Unity `6000.3.28f1`로 연다. 패키지는 URP `17.3.0`, Input System `1.20.1`, uGUI `2.0.0`, Netcode for GameObjects `2.14.0`, Unity Transport `2.7.5`다.
2. 빌드에 켜진 씬은 `Assets/Scenes/Lobby.unity`와 `Assets/Scenes/mainGame.unity`다. `Lobby`에서 방을 만들고 `mainGame`에서 `Cart.prefab`, 플레이어·기병 프리팹, HUD 연결을 확인한다.
3. 웹판을 로컬에서 비교하려면 Node.js `22.13.0` 이상으로 ZIP의 `goblin-getaway/`에서 `npm ci --include=dev`를 실행한다. `node ./node_modules/next/dist/bin/next dev --hostname 127.0.0.1 --port 3000`을 실행하고 `http://127.0.0.1:3000`에서 솔로 또는 테스트 모드로 시작한다.

기존 마차 레이어, 스프라이트 시트 자르기, 포신 반동, 바퀴 장착과 기병의 발굽 그림자·창 정렬은 `Docs/AI/그건님이_Unity_개발가이드_v12.md`를 참고한다. 아래 v13 좌표와 크기를 우선한다. 음악과 편곡 소스는 `goblin-getaway/handoff/music/`에 있다.

이전 버전의 제작 원본과 검증 캡처는 각각 `Handoff/v12/원본/`과 `Handoff/v12/검증화면/`에 있다.

## 대포와 추격 기병

- 청소, 장전, 점화는 같은 작업대 `(641, 0)`이다. 청소 12회, 장전 타이밍 입력, 점화 후 75틱 동안 조준, 발사 순으로 진행한다. 웹 시뮬레이션은 초당 30틱이다.
- 조준 UI는 포구에서 조준점까지의 점선, 중앙 십자선, 점화 중 남은 심지를 나타내는 원형 밧줄로 구성한다. v13 원형 밧줄은 조준점 중심에 배치하며 기존보다 화면상 지름이 약 3배다. 예를 들어 동일한 데스크톱 장면에서 밧줄 너비는 67px에서 199px, 모바일 세로 장면에서는 18px에서 54px였다. 불꽃은 심지가 줄어드는 경계를 따라 돈다.
- `bottom_cannon_aim_count_bar.png`와 `bottom_cannon_aim_count.png`는 40×44다. 밧줄 원의 중심은 스프라이트 중앙보다 아래 2원본 픽셀에 있으므로 배율 적용 후 중심을 조준점에 맞춘다. 밝은 심지 이미지를 남은 시간에 해당하는 각도만큼 표시하고 바탕을 유지한다. 포신 점화 불꽃과 조준점 심지 불꽃은 각 앵커를 사용한다.
- 발사 연기는 회전하고 반동하는 포신의 실제 포구에서 시작한다. 어두운 회색 반투명 픽셀 퍼프를 포구 축을 따라 퍼뜨려 위로 띄운다. `cannon-muzzle-smoke.png`와 `scene.mjs`의 `renderedCannonMuzzle`, `drawCannonBurst`를 참고한다.
- 추격 기병의 아트·신체·그림자·창 시각 디테일은 기존 낮은 배율의 1.5배다. 달리기 시트의 월드 표시 배율은 v12의 `.44`에서 `.66`으로 바뀌었다. 포탄이 빗나가 가까이 지나거나 충격파 가장자리에 아슬아슬하게 걸친 기병은 피해 없이 잠시 움찔하고 빨간 `!!`를 표시한다. 60틱(2초) 동안 이동 속도에 `.75`를 곱한다.

## 마부와 말의 분노

- 마부석에서 왼쪽 스틱을 위아래로 움직이면 `my`에 따라 마차가 가로 도로의 위아래로 연속 이동한다. 최대 속도는 초당 140웹 단위다. 스틱 좌우 입력은 마차 전진과 후진 속도에 영향을 주지 않는다.
- 행동 버튼을 누르면 채찍질 한 번에 게이지가 `1/8`(12.5%p) 오른다. 마지막 채찍질 후 2초가 지나면 초당 `0.10`씩 감소한다. 평상시 속도 배율은 `1 + 0.35 × 분노`다.
- 게이지가 가득 차면 5초 동안 기준 속도의 `1.60`배로 달린다. 이어지는 지침 상태는 12초 동안 `0.55`배다. 작업 안내에 분노 게이지, 폭주 또는 지침 상태와 남은 시간을 표시한다.

## 왕좌와 아이 돌봄

- 왕자 좌석은 웹 `(510, −74)`, 공주 좌석은 `(549, −74)`다. 복귀 장판은 같은 X의 `y=−34`에 두고 왕관 위치 표시는 갈색 실선 테두리 없이 표시한다.
- 마차가 크게 흔들리면 의자와 그 자리에 앉은 아이가 함께 위로 튀었다가 12틱(0.4초)에 걸쳐 원위치로 돌아온다. 이동 중이거나 안겨 있는 아이는 좌석 연출에서 제외한다. 모션 감소 설정에서는 튀는 연출을 생략한다.
- 같은 층에서 아이와 52웹 단위 이내일 때만 도착지 진행 바 아래에 얼굴과 관심 필요, 배고픔, 상태를 표시한다. 두 아이의 얼굴은 `royal-face-prince.png`와 `royal-face-princess.png`다. 관심 필요는 내부 관심 충족값 `100 − attention`으로 계산한다.
- 빈손으로 앉아 있는 아이 가까이에서 행동 버튼을 누르면 하트가 플레이어에서 아이 얼굴로 날아가고 관심 필요가 최대 20%p 줄어든다. 한 번의 효과는 18틱 동안 유지한다. 먹이기, 안아 올리기, 달래기, 좌석 복귀와 장비 작업에는 각각 해당 행동을 우선한다. 온라인 방은 서버에서 가까운 대상과 요청에 명시된 아이가 일치하는지 확인한다.
- 한 아이가 울면 화면 중앙에 작은 울음 자막 하나, 두 아이가 울면 중앙 여러 곳에 큰 자막 다섯 개를 표시한다. 자막은 타이밍 표시 위를 가리면서도 버튼 입력을 통과시킨다. 기존 울음에 따른 이동·간식 제작·타이밍 판정 보정도 사용한다.

## 장판과 HUD

모든 작업 지점 장판의 웹 표시 기준 너비는 48이다. 표시 규격을 공유하고 지점별 상호작용 반경은 유지한다. 지하 포탄 공급 장판을 기존보다 왼쪽으로 장판 너비만큼 이동했고, 포탄 9개 더미는 자리를 유지하면서 폭을 36에서 72로 늘렸다.

| 지점 | 웹 x, y, 반경 | Unity 마차 로컬 x, y, 반경 예시 |
| --- | --- | --- |
| 마부석 | 385, 0, 26 | −1.425, 0, 0.26 |
| 지하 포탄 공급 장판 | 617, 0, 23 | 0.895, 0, 0.23 |
| 지하 포탄 더미 | 665, −1, 표시 너비 72 | 1.375, 0.01, 표시 너비 0.72 |
| 간식 제작 | 383, −21, 24 | −1.445, 0.21, 0.24 |
| 예비 바퀴 | 528, −62, 24 | 0.005, 0.62, 0.24 |
| 계단 | 502, 65, 18 | −0.255, −0.65, 0.18 |
| 대포 작업대 | 641, 0, 26 | 1.135, 0, 0.26 |
| 포탄 적재 장판 | 648, 56, 19 | 1.205, −0.56, 0.19 |

환산 예시는 웹 `(527.5, 0)`을 Unity 마차 로컬 원점으로 두고 100웹 단위를 Unity 1단위로 본 값이다. 실제 프리팹에서는 `CartStations.WorldPerWebUnit`과 좌표·충돌을 함께 맞춘다. 좌우 스프라이트 반전은 실제 이동 방향을 따르며 별도의 캐릭터 색상 이동 삼각형은 표시하지 않는다.

- 랭킹은 화면 왼쪽 위에 유지한다. 플레이어와 봇 모두 점수 내림차순으로 왼쪽부터 가로 배열하고, 동점은 슬롯 순서로 정렬한다. `crew-face-*.png`의 얼굴 크롭과 점수, 이름을 사용한다.
- 작업 안내는 이모티콘 노티와 같은 상단 중앙 위치 및 상자 규격을 사용한다. 작업·이모티콘·시스템 알림 문구는 각 상자 안에서 가운데 정렬한다. 작업 진행도는 진행 바의 채움으로 표시하며, 조준률·분노 게이지 이름과 남은 시간 문구는 필요할 때 표시한다.

## 검증

- 웹판은 Next.js 프로덕션 빌드와 기존 플레이테스트 6개를 통과했다. Chrome에서 아이 근접 UI와 하트 작동, 울음 자막 수와 입력 전달, 알림 정렬, 진행 바 채움, 조준 밧줄 지름을 확인했다. 밧줄은 데스크톱, 모바일 가로·세로, 2인 분할 화면에서 점화 직후와 절반이 지난 시점을 비교했다.
- 재실행은 저장소 루트에서 `node --test tools/playtest/playtest.test.mjs`, `goblin-getaway/`에서 `node ./node_modules/next/dist/bin/next build`를 사용한다.
- Unity 작업을 마치면 Lobby → mainGame 호스트·클라이언트 진입, 마부석 조작과 전체 분노 주기, 대포의 청소부터 발사까지, 기병 피격과 빗나감, 두 아이 상태 및 하트, 순위와 알림 HUD를 확인한다. 씬·프리팹 연결과 Console의 컴파일·런타임 오류를 점검한다.
