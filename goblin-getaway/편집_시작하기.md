# 그건 님이!!! · 다른 기기에서 이어서 편집하기

IDE에서 `package.json`이 있는 `goblin-getaway` 폴더를 연다. 게임 규칙과 Unity 이식은 [Unity 개발 가이드 v10](../Docs/AI/그건님이_Unity_개발가이드_v10.md)를 참고한다.

## 현재 웹판 실행

Node.js 22.13 이상과 npm을 설치하고 다음 명령을 순서대로 실행한다.

```sh
npm ci --include=dev
node ./node_modules/next/dist/bin/next dev --hostname 127.0.0.1 --port 3000
```

`http://127.0.0.1:3000`에서 1인, 한 화면 2인, 테스트 모드를 실행할 수 있다. 배포 전에는 `node ./node_modules/next/dist/bin/next build`로 Vercel과 같은 빌드 진입점을 확인한다. [현재 Vercel 공개판](https://goblin-getaway-crew.vercel.app/)

온라인 협동 개발에는 개인 개발용 Turso 데이터베이스를 사용한다. 터미널 환경에 `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`을 설정하고 `node ./scripts/migrate-rooms-vercel.mjs`를 한 번 실행한 뒤 개발 서버를 시작한다. 방을 만들고 독립된 브라우저 프로필에서 참가한다.

## 이전 ChatGPT Sites v7 실행

Node.js 22.13 이상과 npm을 설치한다. 프로젝트 폴더에서 다음 명령을 한 줄씩 실행한다. 빌드하면 로컬 멀티플레이에 쓸 Wrangler 설정이 생성된다.

```sh
npm run install:ci
npm run build
```

새 기기의 로컬 데이터베이스에는 아래 두 마이그레이션을 순서대로 한 번씩 적용한다. 첫 번째는 방을 생성하고 두 번째는 플레이어 네 명과 방장 승계를 지원하는 열을 추가한다.

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_cloudy_slyde.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_four_player_rooms.sql
```

### Sites 개발 서버

```sh
npm run dev
```

터미널에 표시된 주소를 브라우저에서 연다. 일반 개발 환경의 기본 주소는 http://localhost:5173 이다. 온라인 방 로직을 같은 컴퓨터에서 시험하려면 첫 창에서 방을 만들고, 별도 브라우저 프로필이나 시크릿 창에서 동일한 로컬 주소를 열어 방번호로 참가한다. 실행을 마칠 때는 터미널에서 Ctrl+C를 누른다.

## 개발 자료

handoff 폴더에 초기 기획서와 상세 명세 원본을 편집 가능한 Markdown과 Word로 넣었다. music에는 발표용 BGM 두 곡의 MP3, 원본 WAV, 곡별 Python 편곡·렌더링 소스가 있다. 음원만 사용하려면 MP3 또는 WAV를 열면 된다. 곡을 다시 렌더링하려면 Python의 NumPy·SciPy, FluidSynth와 TimGM6mb.sf2 사운드폰트가 필요하다. 각 render.py에 지정된 사운드폰트 경로를 설치 위치에 맞추고 곡 폴더 안에서 실행하면 mix.wav가 생성된다.
